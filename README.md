# Priscilla Alvarez | Landing Page

Landing page desenvolvida para apresentação profissional de serviços de estética e beleza, com foco em identidade visual, navegação intuitiva e experiência em dispositivos móveis.

**Site publicado:** https://priscillaalvarez.com.br

## Sobre o projeto

O projeto tem como objetivo oferecer uma presença digital profissional para divulgação de serviços de estética, reunindo informações sobre os atendimentos, imagens ilustrativas e canais de contato.

A aplicação utiliza uma arquitetura de frontend estático, sem necessidade de backend, banco de dados ou autenticação.

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS
- HTML5 e CSS3
- Git e GitHub
- Cloudflare Workers
- DNS e domínio personalizado

## Funcionalidades

- Apresentação dos serviços de estética e beleza
- Galeria de imagens
- Layout adaptável para dispositivos móveis
- Informações e canais de contato
- Navegação em página única

## Desenvolvimento e implementação

A versão inicial da interface foi criada com auxílio da plataforma de inteligência artificial Manus.

Posteriormente, o projeto foi preparado como uma aplicação frontend independente, com as seguintes atividades:

- Organização da estrutura estática em React e Vite
- Preparação dos arquivos para publicação
- Configuração do ambiente de hospedagem no Cloudflare Workers
- Registro e configuração do domínio personalizado no Registro.br
- Configuração dos servidores DNS no Cloudflare
- Publicação e verificação inicial do site
- Organização e versionamento do código-fonte no GitHub

O projeto demonstra a utilização de ferramentas de desenvolvimento web, integração de serviços e publicação de uma solução para uma necessidade real.

## Executar localmente

**Pré-requisito:** Node.js e npm instalados.

Clone o repositório:

```bash
git clone https://github.com/carlosbuenodev-coder/priscilla-alvarez-landing-page.git
```

Acesse a pasta:

```bash
cd priscilla-alvarez-landing-page
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

Os arquivos compilados serão gerados na pasta `dist/`.
